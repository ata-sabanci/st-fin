The building block

Anatomy of a slot

Each of the ten slots is one independent rule. You pick what it watches, how it tests, and which side it serves. Off slots are simply ignored.

👁

Variable

Any of the ~67 series — a geometric lens, an oscillator, a volume series, or price.

⚖

Condition + targets

One of 13 conditions, tested against a fixed value or another series. Optionally a second target (A AND/OR B).

🎯

Apply to

Long entry, short entry, long exit, short exit — or block any of these four sides as a veto.

Combining slots

Quorum, not all-or-nothing

A signal does not need every slot to agree. You set a minimum — "how many must pass" — per side.

Set the minimum to 1 and any single slot fires the signal (OR logic). Set it equal to the active count and all must agree (AND logic). Anything between is a true quorum — a majority vote. Each side has its own threshold: long entry, short entry, long exit, short exit.

Try it: drag the slider to change how many of the four active slots must pass. Watch the signal flip.

Inside one slot new

Compare against two targets at once

Each slot can test its variable against two references — a fixed value or another live series — and combine them with AND or OR. One slot, two comparisons.

&

A AND B

Both comparisons must pass. Example: Ceil angle > 30 and RSI > 50 — geometry and momentum aligned.

|

A OR B

Either passes. Example: Flr dist crosses Floor MA or Vol buy > Vol sell — two independent triggers.

Signal veto new

Block slots

Any slot can be set to block instead of support. A single passing block slot kills the signal for that side — a hard veto, regardless of how many other slots agree.

🚫

Block entry

Set a slot to Block long entry or Block short entry. When its condition passes, the entry signal is suppressed even if the quorum is met.

🚫

Block exit

Set a slot to Block long exit or Block short exit. Prevents the exit signal from firing when a specific condition is true.

Use case: you want to enter long when Ceil angle crosses above 30, but not when RSI is already overbought. Set one slot for the entry, another to block long entry when RSI > 80.
When both sides fire

Conflict resolution

If long-entry and short-entry quorums are met on the same bar, you decide what happens.

✕

Block both

Neither enters. The market is indecisive, so you stand aside. The safe default.

↑

Long wins

Long entry takes priority; the short is suppressed.

↓

Short wins

Short entry takes priority; the long is suppressed.

Scaling in

Pyramiding

When an entry signal fires again while a position is already open in that direction, the strategy can add a layer.

Each layer adds the configured equity percentage, up to a maximum you set (1 to 10 layers). The layer counter resets to zero when the position closes. With it off, only the initial entry is placed.

Try it: set the max layers and step through entry signals to watch exposure build.

Profit trail (tight)

Active while the position is in profit. Tracks the best close; if price falls this % from the peak, all layers close. Locks in gains.

🛡

Loss trail (wide)

Active while the position is in loss. A wider band gives the trade room to recover, but still caps the downside. The primary capital protector.

How the switch works: on every confirmed bar close, the strategy checks whether the position is in profit or loss versus the average entry, then applies the matching trail percentage. Exits fire on confirmed close, never on an intrabar wick.
Study & notify

Observe mode and alerts

🔍

Observe mode

No trades execute. Debug labels appear on signal bars with full slot breakdowns. A shadow position tracker mirrors entry, exit, and trail logic with visual labels, so you can study the complete cycle before switching to Backtest.

🔔

Detailed alerts

Four alert types — long entry, short entry, long exit, short exit. Each message can include every active slot with its current value and threshold, plus the trail levels. Toggle slot details and SL/TP lines independently. Pyramid layers fire their own alerts too.

Built-in safeguards: the strategy auto-detects misconfigured slots — inverted "between" bounds, or "diverging/converging" without a comparison series — and warns you on-chart so a silent mistake never costs you a signal.
How a bar resolves

The execution sequence

On each bar, the engine resolves in a fixed order so behaviour is always predictable.

Count the quorum

For each side, count active slots and how many pass their condition.

Check block slots

If any block slot passes for a side, that signal is vetoed regardless of quorum.

Raise raw signals

A side fires if passing slots meet its minimum, no block slot vetoes it, and the framework is active.

Resolve conflict

If both entry sides fire, apply your conflict rule (block / long wins / short wins).

Exits beat pyramids

If an exit and a same-bar pyramid both qualify, the exit wins.

Enter, add, or exit

Enter from flat only (no direct reversal), add a pyramid layer, or close — in Backtest mode only.

Check the dual trail

On confirmed close, apply the profit or loss trail and close all layers if hit.
